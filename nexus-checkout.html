Configurar Pagar.me
1
Criar conta

Acesse pagar.me e crie sua conta. É gratuito e leva cerca de 5 minutos. Você vai precisar de CPF ou CNPJ.

2
Pegar as chaves de API

No painel, vá em Configurações > API Keys. Copie a Secret Key (começa com sk_) e cole no seu .env.

3
Criar os planos de assinatura

Em Assinaturas > Planos, crie dois planos: neXus Básico (R$ 29,90/mês) e neXus Pro (R$ 47,90/mês). Copie o ID de cada um.

4
Configurar Webhook

Em Configurações > Webhooks, adicione: https://seusite.com/webhook/pagarme. Eventos: subscription.created, subscription.canceled, charge.paid.

5
Preencher o .env

Adicione as variáveis abaixo no arquivo .env do servidor e na Vercel.

# Pagar.me PAGARME_SECRET_KEY=sk_live_xxxxxxxxxxxxxxxx PAGARME_PLAN_BASIC=plan_xxxxxxxxxxxxxxxx PAGARME_PLAN_PRO=plan_yyyyyyyyyyyyyyyy PAGARME_WEBHOOK_SECRET=seu-secret-aqui

Código de integração
Webhook do Pagar.me
Adicione esse trecho no server.js para processar os eventos de pagamento.
// api/webhook/pagarme.js export default async function handler(req, res) { const event = req.body; await initDB(); const db = getDB(); if (event.type === 'subscription.created') { const { phone, plan } = event.data.metadata; await db.execute({ sql: 'UPDATE users SET status=?, plan=?, subscription_id=? WHERE phone=?', args: ['active', plan, event.data.id, phone] }); sendWhatsApp(phone, `neXus ${plan} ativado!`); } if (event.type === 'subscription.canceled') { await db.execute({ sql: 'UPDATE users SET status=? WHERE subscription_id=?', args: ['canceled', event.data.id] }); } res.status(200).json({ received: true }); }
Criar assinatura
Chamado quando o usuário preenche o formulário e confirma o pagamento.
// api/criar-assinatura.js const planIds = { basic: process.env.PAGARME_PLAN_BASIC, pro: process.env.PAGARME_PLAN_PRO, }; export default async function handler(req, res) { const { phone, plan, nome, email, cpf, payment } = req.body; const response = await fetch( 'https://api.pagar.me/core/v5/subscriptions', { method: 'POST', headers: { 'Authorization': `Basic ${btoa(process.env.PAGARME_SECRET_KEY + ':')}`, 'Content-Type': 'application/json' }, body: JSON.stringify({ plan_id: planIds[plan], payment_method: payment.method, customer: { name: nome, email, document: cpf }, card: payment.card, metadata: { phone, plan } }) }); const data = await response.json(); res.json({ subscription_id: data.id, status: data.status }); }
